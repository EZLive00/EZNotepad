# 真机功能验证清单

对**打包后的真实程序**（`src-tauri/target/release/EZNotepad.exe`）逐项操作，
不看代码只按用户视角判定。每组用例都在同一个进程内连续执行（启动一次、跑完整组、
退出），避免反复启动。

## 判定依据

| 手段 | 用途 | 可靠性 |
|---|---|---|
| **落盘文件字节** | 编辑类用例的最终判据：操作完 `Ctrl+S`，把文件读回来逐字比对 | 精确，不受视觉误判影响 |
| **窗口截图** | 渲染、布局、状态栏、对话框等只能看的部分 | 需人眼/视觉核对 |
| **截图前后差异** | 判断"有没有反应" | 精确（字节比对） |

截图统一落在 `D:/tmp/ez-real/`。测试文档本身不放结果，结果在 `RESULTS.md`。

直接起，要么从主窗口的菜单进去。点击坐标一律按窗口矩形换算（窗口铺满工作区时

（`dlgpick` 动作，实现在 `lib.ps1` 的 `Dlg-Pick`）；对话框真正关闭后
