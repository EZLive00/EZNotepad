# EZNotepad

> 一個 **5MB** 的桌面小工具：Markdown 寫作 + 文字讀寫 + 檔案對比。
> 免安裝、不聯網、雙擊就用。
> 介面支援 9 種語言，預設跟隨系統語言，也可以在「設定 → 語言」裡手動切換。

| 產物 | 適合誰 |
|---|---|
| `EZNotepad_<版本>_x64-setup.exe` | **安裝版**：安裝嚮導 + 檔案關聯，雙擊 `.md` / `.txt` 直接開啟 |

- 目前僅提供 Windows x64 構建包

## 三種模式（一個下拉，按檔案型別自動適配）

| 模式 | 做什麼 | 快捷 |
|---|---|---|
| **所見即所得** | 輸入 `# ` 變標題、`**粗**` 立刻加粗 | `Ctrl+1` |
| **編輯模式** | 看原始 Markdown / 原始碼，帶行號、語法著色、摺疊 | `Ctrl+2` |
| **預覽模式** | 只讀渲染，專注閱讀 | `Ctrl+3` |

**支援的檔案型別**：`.md`（三種模式全開）、`.json`（校驗 + 高亮 + 錯誤定位）、
`.txt` `.log` `.csv`、常見程式碼檔案（`.js/.ts/.py/.rs/.go/.html/.css/.sql/.yml/...`）。
**新建時會讓你先選型別**（Markdown / 純文字 / JSON / CSV / 程式碼），非 Markdown 的檔案
只開放「編輯 / 預覽」，當成普通文字編輯器用。

## 編輯模式用的是 CodeMirror 6

不是套了個 `<textarea>`。真正帶程式碼編輯器的那一套：

| | 說明 |
|---|---|
| **語法著色** | JS/TS/JSX、Python、Rust、Go、Java、C/C++、JSON、CSS、HTML、SQL、YAML、Shell、INI、Markdown，增量解析 |
| **行號 / 當前行** | 行號槽、當前行底色、括號匹配、程式碼摺疊 |
| **撤銷** | CM6 自己的事務級 history，比瀏覽器的 contenteditable 靠譜 |
| **大檔案** | 只渲染可視行。實測 5 萬行開啟 49ms，10 萬行 20ms，DOM 裡只留一百多行 |
| **縮排** | Tab 有選區縮整段、沒選區縮當前行；Shift+Tab 反縮排；回車沿用上一行縮排 |
| **括號配對** | 打 `(` 自動補 `)`、引號同理；游標停在一對中間時，再打右括號是「跳過去」而不是插一個 |
| **主題** | 明暗兩套跟隨應用切換，語法配色與預覽共用同一組 CSS 變數 |

配色只在 `styles.css` 的 `body[data-theme]` 裡定義一次，編輯器和預覽渲染器各取一次，
不存在兩套色值對不上的問題。

不支援的選項會自動置灰 —— 開啟 JSON 時「所見即所得」會變灰，不會讓你誤點。

## 介面分割槽（每個功能只有一個入口）

```
┌──────────────────────────────────────────────┐
│ ▣ 檔案 編輯 格式 檢視 工具 幫助  歡迎.md  － □ ✕│ ← 標題欄（40px）
├──────────────────────────────────────────────┤
│ 歡迎.md × │ test.json × │ +         編輯▾ ⌕ 儲存 │ ← 標籤與工具同一行
├────────┬──────────────────┬──────────────────┤
│        │                  │                  │
│ 大綱   │   編輯 / 所見即所得 │      預覽        │
│        │                  │                  │
├────────┴──────────────────┴──────────────────┤
│ 行 1,列 1 │ 36 行 │ 243 字 │ Markdown │ LF │ UTF-8 │ 已儲存 │
└──────────────────────────────────────────────┘
```

內容區上方只有兩行：標題欄（選單 + 文件標題 + 視窗按鈕），以及標籤與工具合起來的一行
（左邊標籤、右邊只放**模式切換 / 查詢 / 儲存**三個高頻動作，其餘全部在選單裡，不重複擺放）。
視窗變窄時工具退成純圖示。

視窗沒有系統標題欄（`decorations: false`）：選單、文件標題、視窗按鈕都在最上面一行，
中間空白處可以拖動視窗，雙擊最大化 —— 和 VS Code、WorkBuddy 這類應用一致。
視窗四角用 Win11 的 DWM 原生圓角，拖動邊緣仍可縮放。
「檢視 → 標題欄顯示檔名」可以關掉標題文字，只留選單和按鈕。

- **大綱** —— 只管導航
- **側欄** —— 兩頁：大綱（跟隨滾動高亮當前章節）／檔案（目錄樹 + 全目錄搜內容）
- **工具行** —— 只有模式、查詢、儲存三個高頻動作，其他命令一律走選單
- **正文區** —— 只管編輯
- **狀態列** —— 只管資訊，編碼和換行符可點選修改
- **選單** —— 只管全集入口
- **設定** —— `Ctrl+,` 一個面板：主題、字號、介面、自動儲存、工作資料夾
- **對比中心** —— 獨立全屏面板，不和編輯器揉在一起

### 側欄「檔案」頁：目錄樹與跨檔案搜尋

- 展開一層讀一層（懶載入），開啟大倉庫不會先把幾萬個檔案讀進來
- **右鍵就能改**：在任意目錄下新建檔案 / 資料夾，給檔案改名，或者刪除
  - 刪除進**系統回收站**，誤點了還能撈回來；資料夾只刪空的，不會連鍋端
  - 改名或刪除時，已經開啟的那個標籤會跟著走（不會指著舊路徑再寫回去）
- 搜尋在 Rust 裡掃，跳過二進位制與 4MB 以上的檔案，最多返回 200 條
- 搜尋框上的 `.*` 切正則、`Aa` 區分大小寫
- 結果按檔案分組，帶行號與片段，點一下開啟並跳到那一行
- **跨檔案替換**：搜尋框下面填「替換為」，點「全部替換」。會先問一次，說明要動磁碟；
  改每個檔案之前都留一份歷史快照，出問題能找回
- 記住上次開啟的資料夾；設定面板裡可以換或清空

### 查詢（`Ctrl+F` / `Ctrl+H`）

一個浮層兩種狀態：點最左邊的箭頭展開成「查詢 + 替換」兩行，收起就只剩查詢。
`Ctrl+F` 只管聚焦（不會把已經攤開的替換行收回去），`Ctrl+H` 直接展開。

| 能力 | 說明 |
|---|---|
| **所見即所得裡原位查詢** | 不再為了查詢切到編輯模式；高亮畫在渲染層上（CSS Highlight API），不往正文裡插標記 |
| **模式開關** | 輸入框右側四個小方格：`Aa` 區分大小寫、`.*` 正則、`全詞`、`選區`。啟用時走 accent 色 |
| **整詞** | 只在查詢串兩端是英文單詞字元時加邊界——中文沒有詞邊界，硬套 `\b` 會永遠匹配不到 |
| **選區內** | 只在選中的那段裡查詢/替換，沒選中時這一項是灰的 |
| **換行** | 輸入框右端的 `↵`（或 `Ctrl+Enter`）插一個換行，框會自己長高；不帶換行的查詢照舊不會跨段假命中 |
| **替換** | 命中在同一段文字內時**直接就改**，不彈窗；只有跨越加粗/連結這類格式邊界才問「是否切到編輯模式」 |
| **跨檔案** | 側欄「檔案」頁的搜尋框，按檔案分組列出命中行 |

## 幾種用得最多的功能

### 所見即所得：真的能當編輯器用

不只是「輸入 `# ` 變標題」，塊級結構都能直接操作，Markdown 語法與所見即所得雙向一致。標記只要落在**行首**就行，不必寫在行尾——文字先寫好，回頭在行首補一個 `## ` 一樣升級成標題，標記後面的文字（連同加粗、連結）原樣保留：

| 能力 | 怎麼用 |
|---|---|
| **標題 / 正文** | 行首輸 `# `～`###### `（已有文字前面補也行）；`Ctrl+Alt+1~3` 換級，再按一次回正文 |
| **無序 / 有序 / 任務列表** | 行首輸 `- ` / `1. ` / `- [ ] `；`Tab` 縮排成子項、`Shift+Tab` 退一級 |
| **巢狀列表** | 最多 6 層，切換有序/無序不會丟層級，序號自動重排 |
| **引用** | 行首輸 `> `；`Tab` 增加引用層級，空行回車即退出 |
| **程式碼塊 / 分割線** | 行首輸 ` ``` ` / `---`；程式碼塊裡回車自動換行、縮排兩格 |
| **表格** | `Ctrl+Shift+T` 插 3×3，或「格式 → 插入表格（自定大小）」 |
| **表格編輯** | `Tab` / `Shift+Tab` 在單元格間移動（到末尾自動加行）、`Enter` 到下一行同列、右鍵增刪行列與列對齊 |
| **行內樣式** | 輸入 `**粗**`、`*斜*`、`~~刪~~`、`` `碼` ``、`[文字](連結)` 邊打邊變 |
| **數學公式** | 行內 `$a^2+b^2=c^2$`、塊級 `$$ … $$`（可跨行），預覽裡由 KaTeX 排版 |
| **目錄** | 「插入 → 目錄…」掃一遍標題生成可點選的列表，`Ctrl+點選` 條目跳到對應章節 |
| **插入圖片** | 截圖後直接 `Ctrl+V`、或把圖片檔案拖進視窗、或「插入 → 圖片…」：都會複製到文件同目錄 `assets/` 用相對路徑引用；也可以直接填網路地址 |
| **圖片尺寸** | 所見即所得裡拖圖片右下角直接改寬（拖完自動寫進 alt 字尾）；也可以手寫 `![說明\|300](a.png)` 限寬、`![說明\|300x200](a.png)` 限寬高；不寫就按原比例顯示（最高 320px） |
| **退格語義** | 標題行首退格先把 `###` 亮出來、再一級一級往回刪；列表項開頭退格先降級、再變段落；段落開頭退格併入上一行；`Delete` 反向同理 |
| **貼上** | 多行文字按 Markdown 解析成真正的標題/列表/表格塊，不會糊成一坨 |

**行首塊手柄**：游標或滑鼠所在那一行的左邊會浮出 `+` 和 `⋮⋮` 兩個小按鈕（不會蓋住字，也選不中）。
`⋮⋮` 把這一塊換成別的型別（正文 / 標題 1~3 / 列表 / 引用 / 程式碼塊），`+` 在下方插入新塊。
它和頂欄「格式」選單執行的是同一套命令，只是把入口挪到了手邊。

標題的 `###` 只在你要改級別時才出現：行首按一次退格亮標記（正文一個字不動），再按就刪掉一個 `#`，刪光才退回正文——手滑按到退格不會把級別和文字一起弄丟。游標移開這一行或按回車，標記自動收起。

標記認的位置是「游標前面這一小段」而不是整個行尾，所以三種寫法等價：先打 `## ` 再寫標題、寫完標題回行首補 `## `、把一段普通文字升級成標題。只剩標記本身才認（`## ` 後面緊跟空格），所以正文裡的 `#話題` 不會被誤轉成標題；游標不在行首時輸 `- ` 也不會把句子拆成列表。

所有塊級操作也在 **「格式」選單** 和 **右鍵選單** 裡，且會用不到的項自動置灰（比如游標不在表格裡時表格局命令全灰）。

### 數學公式

- 行內 `$a^2 + b^2 = c^2$`、塊級 `$$ … $$`（允許跨行，矩陣和多行推導不必擠成一行）
- 渲染只發生在**預覽側**：KaTeX 是「真的遇到公式才載入」的（約 546 KB），不寫公式的文件一分錢都不付
- 所見即所得裡公式不渲染、只加一層底色 —— 往 contenteditable 裡塞 KaTeX 的 DOM，退格刪不掉、游標會卡住，代價遠大於收益。要看成 `Ctrl+3`，或者開雙欄讓預覽就在旁邊
- 公式段在解析強調語法**之前**就被保護起來，所以 `$x_1 * y$` 裡的 `_` 和 `*` 是下標與乘號，不會被當成斜體

### 專注模式（`F9`，`Esc` 退出）

標籤行、側欄、狀態列、選單全部收起來，只剩正文。標題欄會淡到幾乎看不見，滑鼠移上去才恢復 —— 視窗是無邊框的，要是連標題欄都沒了就沒法拖、沒法最小化關閉，等於把人關在自己寫的文件裡。

### 雙擊就能開啟 / 只開一個視窗

安裝包裝好之後，`.md` `.markdown` `.txt` `.log` `.json` `.csv` 都註冊了檔案關聯，
在資源管理器裡右鍵「開啟方式」就能找到「EZNotepad」。

同一個程式只會有一個視窗：再雙擊一個檔案，不會起第二個程序，
而是把路徑交給已經開著的視窗開啟（順帶把它從最小化叫回來）。
兩個視窗同時改一個檔案、互相覆蓋這種事，從源頭上沒有了。

> 只有**安裝版**會註冊關聯。免安裝版和 `cargo build` 出來的裸 exe 都不寫登錄檔。

### 檔案變化監聽

已開啟的文件會被實時盯著（後端用系統的 `ReadDirectoryChangesW` / `inotify`，只監聽檔案所在目錄這一層，並且只放行名單裡的檔名）。別的程式改動檔案時：

- 檔案在**當前標籤**：沒改過就靜默過載並提示；有未儲存的修改就先問
- 檔案在**後臺標籤**：不彈窗打擾，標籤上冒一個琥珀色小點，切過去時才問

自己儲存不會自激（儲存後修改時間已同步）。設定裡可以整體關掉。

### 一鍵格式化（按檔案型別智慧處理）

| 型別 | 做什麼 |
|---|---|
| **JSON** | 校驗 + 重排縮排；自動修正全形引號、多餘逗號、註釋；**語法錯誤時不改檔案，彈出「第 X 行第 Y 列」** |
| **Markdown** | 標題前後補空行、列表符號統一、去行尾空格、壓縮空行 |
| **TXT / 日誌 / 程式碼** | 統一換行符、去行尾空格、壓縮連續空行 |

格式化後可一鍵「撤銷」回到原樣。

### 歷史版本（檔案 → 歷史版本…）

每儲存一次，**儲存前**的內容就留一份快照，存在本機應用資料目錄（不往你的文件目錄裡塞東西）。
一鍵格式化、排序去重、批次替換之後想反悔，`Ctrl+Z` 未必翻得回去，這裡是最後一道。

- 每個檔案最多留 60 份、總量 20MB，超了從最舊的開始清
- 「檢視」把那一版開成只讀新標籤，「恢復」寫回編輯器 —— **都要你自己按 `Ctrl+S` 才動磁碟**
- 和檔案對比、三向合併同一個原則：回滾不直接覆蓋原檔案

### 匯出網頁（檔案 → 匯出網頁…）

把當前文件存成一個**單檔案 HTML**：樣式內嵌、圖片轉成 data URI，
發給別人或者丟進靜態站點都能直接開啟，不會出現「圖全裂了」。
圖片超過 4MB 的不內嵌（保留原地址），匯出提示裡會說內嵌了幾張。

### 命令面板（`Ctrl+Shift+P`）

選單裡那一百多條命令，輸幾個字就能定位：`專注`、`格式`、`替換` 都行，
`↑` `↓` 選、`Enter` 跑、`Esc` 關。列表直接從選單樹生成，選單加了新命令這裡自動有。
當前狀態下用不了的命令會灰掉，點了會告訴你為什麼。

### 快捷鍵自己改（設定 → 快捷鍵）

設定面板裡列著所有帶快捷鍵的命令，點「改」之後直接按新的組合鍵（要帶 `Ctrl` / `Alt`，
或者單用 `F1`–`F12`），`Esc` 取消。自定義的鍵優先於預設鍵位，改壞了點「恢復」就回來，
「恢復預設設定」會一併清空。

### 文字對比（`Ctrl+D`）

- 左右並排，**行級 + 字元級**雙重高亮（只標出真正改動的幾個字）
- 忽略空白 / 忽略大小寫
- `F7` / `F8` 在差異之間跳躍
- 每個差異塊帶 **→** 按鈕，一鍵把左邊這塊同步到右邊
- 一鍵匯出 HTML 對比報告

### 資料夾對比

遞迴比兩個目錄，列出 **僅左 / 僅右 / 已修改 / 相同**，點一行直接進入該檔案的文字對比。

### 三向合併（工具 → 三向合併）

選「基準版本 + A 側 + B 側」，自動合併兩邊改動，衝突處列清單。
**結果只在新標籤開啟，絕不覆蓋任何原檔案。**

### 編碼與換行符

狀態列右下角點 `UTF-8` 可以換編碼另存（UTF-8 / GBK / UTF-16，可加 BOM）；
點 `LF` 切換 CRLF。開啟 GBK 的老 txt 不會亂碼。

## 資料與隱私

- 所有檔案只在你電腦上讀寫，**不聯網、不上傳**
- 草稿儲存在本機應用資料目錄，關掉視窗不會丟：**所有**沒儲存的標籤都會存下來，
  下次啟動時一起問你要不要恢復（不是隻保最後一個）
- 歷史快照也在這個目錄下的 `history/`，和你的文件目錄完全分開
- 首次開啟如果檢測到未儲存的草稿，會詢問是否恢復

## 已知限制

- PDF 匯出走系統列印對話方塊（「另存為 PDF」），排版以列印效果為準
- 三向合併為半自動版：自動合併 + 衝突清單，不做四欄視覺化合並器（複雜衝突建議用文字對比逐塊處理）
- 各平臺安裝包需在對應系統上構建（詳見 `構建說明.md`）
- 跨檔案搜尋預設按字面、不區分大小寫，可切正則；上限 200 條
- 跨檔案替換隻處理 **UTF-8** 檔案：GBK 之類原樣跳過，不悄悄改掉整個檔案的編碼
- 檔案樹裡的刪除進系統回收站；**資料夾只能刪空的**，不會遞迴刪
- 檔案**樹**本身不監聽：在別處新建/刪除的檔案要在空白處右鍵「重新整理」或重新展開目錄（已開啟的文件會被實時監聽，見上文）
- 數學公式只在預覽側渲染，所見即所得裡顯示原始碼；Mermaid 圖表尚未支援
