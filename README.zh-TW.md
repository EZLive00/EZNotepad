# EZNotepad

> 一個 **5 MB** 的桌面小工具：Markdown 寫作 + 文字編輯 + 檔案對比。
> 免安裝、不聯網、雙擊即用。
> 介面支援 9 種語言，預設跟隨系統，可在 **設定 → 語言** 裡手動切換。

## 下載

| 產物 | 適合誰 |
|---|---|
| `EZNotepad_<版本>_x64-setup.exe` | **安裝版** —— 安裝嚮導 + 檔案關聯，雙擊 `.md` / `.txt` 直接在這裡開啟 |
| `EZNotepad_<版本>_x64-portable.zip` | **便攜版** —— 解壓到任意目錄，雙擊 `EZNotepad.exe`（不寫登錄檔、不建關聯） |

沒有程式碼簽名，首次啟動會被 SmartScreen 攔一次：點 **更多資訊 → 仍要執行**。
目前只有 Windows x64；便攜版依賴系統自帶的 WebView2（Win10 / Win11 預裝）。

## 替換掉什麼

| 以前用 | 為什麼 | 現在 |
|---|---|---|
| 記事本 | 開任意文字、換編碼、看日誌 | 一樣能開，外加行號、高亮和大綱 |
| Typora | Markdown 邊寫邊看 | 三種模式，體積只有二十分之一 |
| BeyondCompare | 對比兩個檔案 | 並排、字元級標記，`F7` / `F8` 逐處跳轉 |

## 三種模式

| 模式 | 做什麼 | 快捷鍵 |
|---|---|---|
| **所見即所得** | 行首敲 `# ` 出標題，`**加粗**` 邊打邊變 | `Ctrl+1` |
| **編輯** | 原始 Markdown / 原始碼，CodeMirror 6，行號與摺疊 | `Ctrl+2` |
| **預覽** | 只讀渲染，為閱讀而生 | `Ctrl+3` |

`.md` 三種模式全支援；`.json` 有校驗和錯誤定位；`.txt` `.log` `.csv` 與程式碼檔案
（`.js .ts .py .rs .go .html .css .sql .yml` …）只有編輯 / 預覽，當純文字編輯器用。
新建檔案先選型別（Markdown / 純文字 / JSON / CSV / 程式碼）。

## 編輯

| | |
|---|---|
| **塊級** | 行首 `# ` 標題、`- ` / `1. ` / `- [ ] ` 列表（6 級）、`> ` 引用、` ``` ` 程式碼、`---` 分割線 —— 標記只要求落在行首 |
| **行內** | `**粗**`、`*斜*`、`~~刪~~`、`` `碼` ``、`[文字](連結)` 邊打邊渲染 |
| **撤銷 / 重做** | 工具列最左兩個箭頭（退到頭變灰），`Ctrl+Z` / `Ctrl+Y`，`Ctrl+Shift+Z` 同重做 —— 所見即所得與純文字各走自己的歷史堆疊，互不干擾 |
| **表格** | `Ctrl+Shift+T` 插入；`Tab` 走格子，`Enter` 跳到下一行同列，右鍵增刪行列與對齊 |
| **圖片** | 貼上截圖、拖入檔案或 **插入 → 圖片**：檔案會複製到文件旁的 `assets/`。拖右下角改寬度，或手寫 `![說明\|300](a.png)` |
| **公式** | `$a^2+b^2=c^2$` 行內、`$$ … $$` 整塊，預覽裡由 KaTeX 排版（有公式才載入） |
| **提示塊** | `> [!info]` / `warning` / `danger` / `success`，GitHub 的別名也認 |
| **塊手柄** | 行首浮出 `+` 與 `⋮⋮`：插入新塊，或把當前塊換成別的型別 |
| **貼上** | 多行文字按 Markdown 解析成真正的標題、列表、表格，而不是糊成一段 |

換塊型別（`Ctrl+Shift+Q` 引用、`Ctrl+Shift+K` 程式碼…）、**格式**選單、右鍵選單和
`Ctrl+Shift+P` 命令面板走的是同一套命令，不適用的項自動變灰。

### 查詢替換

一個浮層兩種狀態：`Ctrl+F` 只聚焦，`Ctrl+H` 直接展開替換行。**所見即所得裡也能直接搜**，
高亮畫在渲染層上，不往正文裡塞標籤。

`Aa` 區分大小寫 · `.*` 正則 · 全詞匹配（只有兩端都是英文字元時才加詞邊界，中文沒有詞邊界）·
選區中查詢 · `↵` 在查詢裡換行。同一段文字內的匹配就地替換，只有跨粗體、連結這類格式邊界時才提示切到編輯模式。

## 對比

`Ctrl+D`（或 `Ctrl+Shift+N`）開啟對比視窗，預設是空的 —— 怎麼進由你決定：

- **兩個檔案** —— 側欄「檔案」頁裡用 `Ctrl` / `Shift` 多選，右鍵 → **比較這兩個檔案**（右鍵的那個在左邊）
- **兩段文字** —— 點 **貼上兩段文字**，兩邊直接粘，不落盤也能比
- **直接改** —— 點 **編輯** 兩側都變可寫；**儲存** 只寫回真有磁碟檔案的那一邊

行級標記指出哪行變了，字元級標記指出變了哪幾個字。`F7` / `F8` 逐處跳，**匯出報告** 生成獨立的 HTML 對比頁。
右側刻度尺對應整篇的位置——懸停看行號，點擊或拖曳定位；**差異清單** 把每處改動列成可排序、可篩選的清單（位置 / 類型 / 行數）。
**排序** 把兩側的行按字典序重排（空行留末尾），順序噪音不再淹沒真正的增刪；`Ctrl+Z` 復原。
編輯模式下打字、Enter 換行、縮排、刪選取範圍、排序都能 `Ctrl+Z` 復原 / `Ctrl+Y` 重做（焦點在工具列上也有效）。
工具列上也有這兩個按鈕，退到頭時自動變灰；視窗拉窄時這一列先收成圖示，不會把右邊的按鈕裁掉。
單側上限 8MB / 5 萬行，超出會說明原因，不靜默失敗。

**資料夾對比** 遞迴列出「左邊獨有 / 右邊獨有 / 內容不同 / 相同」，點一行就進文字對比。
**三向合併** 選「基準 + A + B」，自動合併並列衝突 —— 結果只開新標籤，絕不覆蓋原檔案。

## 檔案與搜尋

側欄兩頁：**大綱**（滾動時高亮當前章節）和 **檔案**。

- 目錄樹按需展開；右鍵新建、重新命名、刪除 —— 刪除進**回收站**，資料夾只允許刪空目錄
- 搜尋在 Rust 裡跑，跳過二進位制與 4 MB 以上的檔案，最多 200 條，按檔案分組帶行號
- `.*` 切正則，`Aa` 切大小寫
- **全部替換**跨檔案，先問一次，每個檔案改前都留快照
- 開啟的文件實時監聽（`ReadDirectoryChangesW`）：當前標籤靜默過載，後臺標籤亮個黃點，切過去時再問

## 其它

| | |
|---|---|
| **一鍵格式化** | `Ctrl+Shift+F` —— JSON 校驗 + 重排（出錯時不動檔案，只報行列），Markdown 補空行、統一列表符號，其餘去行尾空白。一次 `Ctrl+Z` 全還原 |
| **歷史版本** | 每次儲存前留一份（每檔案 60 份、共 20 MB）。**檢視** 只讀開啟，**恢復** 寫回編輯器 —— 不按 `Ctrl+S` 就不落盤 |
| **匯出** | 單檔案 HTML（樣式內聯、圖片轉 data URI）；PDF 走系統列印對話方塊 |
| **快捷鍵** | 設定 → 快捷鍵 可改任意一條；自定義優先，**重置**恢復單條，**恢復預設**清空全部 |
| **專注模式** | `F9` 收起標籤、側欄、狀態列和選單；標題欄只降到 28% 不消失，否則視窗沒法拖、沒法關 |
| **單例項** | 再雙擊一個檔案不會開第二個程序，路徑交給已在執行的視窗 |
| **編碼** | 點狀態列的 `UTF-8` 或 `LF` 換編碼（GBK / UTF-16 / BOM）與行尾 |

## 效能

本機實測（Windows 11，x64，release 構建）：

| 場景 | 指標 |
|---|---|
| 600 段文件裡打字 | 每鍵 **9.1 ms** |
| 開啟 10.8 MB / 77,866 塊 | **1.14 s**，DOM 裡只留約 48 塊，不卡 |
| 同一文件打字 / 滾動 / 撤銷 | p50 **0.3 ms** / 每幀約 **17 ms** / 每步 **37 ms** |
| CodeMirror 6 純文字 | 5 萬行 **49 ms**，10 萬行 **20 ms** |
| 記憶體 / 安裝包 | 乾淨啟動約 **170 MB** / **2.63 MB** |

超大 Markdown 走視口渲染：只有看得見的塊進 DOM，其餘全是記錄；撤銷快照就是記錄陣列，
敲一個字不會複製整篇文件。

## 資料

所有檔案只在本機讀寫 —— **不聯網、不上傳、不埋點**。未儲存標籤的草稿放在本地應用資料目錄，
下次啟動時問你要不要恢復；歷史快照在同目錄的 `history/` 下，跟你的文件目錄完全分開。

## 已知限制

- PDF 走系統列印對話方塊，排版跟列印輸出一致
- 三向合併是「自動合併 + 衝突列表」，沒有四欄視覺化合並器（複雜衝突用文字對比逐塊過）
- 公式只在預覽渲染，所見即所得裡顯示原始碼；暫不支援 Mermaid
- 跨檔案替換隻處理 UTF-8，GBK 等編碼直接跳過，不會悄悄整篇重編碼
- 檔案樹本身不監聽，外部增刪後在右鍵選單裡 **重新整理**
- 各平臺安裝包必須在對應系統上構建（見 `docs/構建說明.md`）；架構設計與跨平臺移植說明在 `docs/` 目錄
