# EZNotepad

> **5 MB** 데스크톱 도구: Markdown 작성 + 텍스트 편집 + 파일 비교.
> 설치 없이, 오프라인으로, 더블클릭 한 번에 실행.
> UI는 9개 언어를 지원하며 시스템 언어를 따르고, **설정 → 언어**에서 직접 바꿀 수 있습니다.

## 다운로드

| 파일 | 누구에게 |
|---|---|
| `EZNotepad_<버전>_x64-setup.exe` | **설치 버전** — 설치 마법사와 파일 연결. `.md` / `.txt`를 더블클릭하면 여기서 열립니다 |
| `EZNotepad_<버전>_x64-portable.zip` | **포터블** — 아무 폴더에 풀고 `EZNotepad.exe` 실행 (레지스트리도 연결도 건드리지 않음) |

현재는 Windows x64만 지원합니다. 포터블 버전은 시스템에 있는 WebView2를 씁니다 (Win10 / Win11 기본 포함).

## 세 가지 모드

| 모드 | 하는 일 | 단축키 |
|---|---|---|
| **WYSIWYG** | 줄 앞에 `# `를 치면 제목, `**굵게**`는 입력하는 대로 반영 | `Ctrl+1` |
| **편집** | 원본 Markdown / 소스. CodeMirror 6, 줄 번호와 접기 | `Ctrl+2` |
| **미리보기** | 읽기 전용 렌더링, 읽기에 집중 | `Ctrl+3` |

`.md`는 세 모드 모두 지원. `.json`은 검증과 오류 위치 표시. `.txt` `.log` `.csv`와 코드 파일
(`.js .ts .py .rs .go .html .css .sql .yml` …)은 편집 / 미리보기만 제공해 일반 텍스트 편집기처럼 씁니다.
새 파일은 먼저 종류를 고릅니다 (Markdown / 일반 텍스트 / JSON / CSV / 코드).

## 편집

| | |
|---|---|
| **블록** | 줄 앞 `# ` 제목, `- ` / `1. ` / `- [ ] ` 목록(6단계), `> ` 인용, ` ``` ` 코드, `---` 구분선 — 마커는 줄 앞에만 있으면 됩니다 |
| **인라인** | `**굵게**`, `*기울임*`, `~~취소선~~`, `` `코드` ``, `[글자](링크)`를 치는 대로 렌더링 |
| **실행 취소 / 다시 실행** | 도구 모음 맨 왼쪽 두 화살표(끝에 닿으면 회색), `Ctrl+Z` / `Ctrl+Y`, `Ctrl+Shift+Z`도 다시 실행 — WYSIWYG과 일반 텍스트는 각자의 기록을 따로 씁니다 |
| **표** | `Ctrl+Shift+T`로 삽입. `Tab`으로 셀 이동, `Enter`는 아래 줄 같은 열로, 우클릭으로 행·열 추가/삭제와 정렬 |
| **이미지** | 스크린샷 붙여넣기, 파일 끌어놓기, **삽입 → 이미지**: 문서 옆 `assets/`로 복사됩니다. 오른쪽 아래를 끌어 너비 조절, `![설명\|300](a.png)` 직접 작성도 가능 |
| **수식** | `$a^2+b^2=c^2$`는 인라인, `$$ … $$`는 블록. 미리보기에서 KaTeX가 조판합니다 (수식이 있을 때만 로드) |
| **콜아웃** | `> [!info]` / `warning` / `danger` / `success`, GitHub 별칭도 인식 |
| **블록 핸들** | 줄 앞에 `+`와 `⋮⋮`가 떠오릅니다: 블록 삽입, 또는 이 블록을 다른 종류로 변환 |
| **붙여넣기** | 여러 줄 텍스트를 Markdown으로 해석해 진짜 제목·목록·표로 만듭니다 (한 덩어리로 뭉치지 않음) |

블록 종류 변경(`Ctrl+Shift+Q` 인용, `Ctrl+Shift+K` 코드…), **서식** 메뉴, 우클릭 메뉴,
`Ctrl+Shift+P` 명령 팔레트는 모두 같은 명령 집합을 씁니다. 쓸 수 없는 항목은 알아서 흐려집니다.

### 찾기와 바꾸기

오버레이 하나에 두 가지 상태: `Ctrl+F`는 포커스만, `Ctrl+H`는 바꾸기 줄까지 엽니다.
**WYSIWYG 상태에서 그대로 검색**됩니다 — 강조는 렌더링 층에 그려지고 본문에 태그를 넣지 않습니다.

`Aa` 대소문자 구분 · `.*` 정규식 · 단어 단위(양끝이 영문일 때만 경계를 넣습니다. 중국어에는 단어 경계가 없음) ·
선택 영역 안 · `↵`로 검색어에 줄바꿈 삽입. 같은 서식이 이어진 텍스트는 그 자리에서 바꾸고, 굵게나 링크를 가로지를 때만 편집 모드로 전환할지 묻습니다.

## 메모

`Ctrl+Shift+M`(또는 메뉴 막대의 **메모**)으로 한 곳에 고정된 임시 메모를 엽니다.

- **저장 필요 없음** — 입력이 멈추고 약 0.35초 뒤 디스크에 기록되며, 탭이나 창을 닫기 전에도 마저 씁니다. 저장 안 됨 표시도, "저장할까요?" 질문도 없습니다
- **위치는 고정** — `<앱 데이터 폴더>/quicknote.md`. **파일 → 메모**에 위치가 표시되고 탐색기에서 열 수도 있습니다
- **이어서 쓰기** — 열면 커서가 끝에 있습니다. **현재 시각 삽입**으로 `2026-11-03 09:20`
- **비우기도 되돌릴 수 있음** — **메모 비우기**는 먼저 「기록」에 사본을 남깁니다

여전히 평범한 Markdown 탭입니다(모드 전환·내보내기·검색). 다만 「최근 연 항목」과 이전 탭 복원에는 들어가지 않습니다.

## 비교

`Ctrl+D`(또는 `Ctrl+Shift+N`)로 비교 창이 열립니다. 내용은 비어 있는 것이 기본 — 들어가는 방법은 자유입니다:

- **두 파일** — 사이드바 "파일"에서 `Ctrl` / `Shift`로 여러 개 선택 후 우클릭 → **이 두 파일 비교** (우클릭한 쪽이 왼쪽)
- **두 텍스트** — **두 텍스트 붙여넣기**를 누르고 양쪽에 붙여넣기. 파일 없이도 비교됩니다
- **바로 편집** — **편집**을 누르면 양쪽이 편집 가능해지고, **저장**은 실제 파일이 있는 쪽에만 기록합니다

줄 단위 표시가 어느 줄이 바뀌었는지, 문자 단위 표시가 어느 글자가 바뀌었는지 알려줍니다. `F7` / `F8`로 차이를 이동하고, **보고서 내보내기**로 단독 HTML 비교 페이지를 만듭니다.
오른쪽 눈금자는 전체에서의 위치를 나타내며, 마우스를 올리면 줄 번호가 보이고 클릭하거나 끌어서 이동합니다. **차이 목록**은 각 변경을 정렬·필터링할 수 있는 목록으로 보여 줍니다(위치 / 유형 / 줄 수).
**정렬**은 양쪽 행을 사전순으로 재배열합니다(빈 줄은 끝). 순서 차이가 실제 추가·삭제를 가리지 않습니다. `Ctrl+Z`로 되돌립니다.
편집 모드에서는 입력, 줄바꿈, 들여쓰기, 선택 영역 삭제, 정렬 모두 `Ctrl+Z` / `Ctrl+Y`로 실행 취소·다시 실행할 수 있습니다(포커스가 도구 모음에 있어도 동작합니다).
도구 모음에도 같은 두 버튼이 있으며(스택 끝에서는 회색), 창이 좁아지면 이 줄이 아이콘으로 접혀 오른쪽 버튼이 잘리지 않습니다.
한쪽 상한은 8MB / 5만 줄이며, 넘으면 이유를 명시합니다.

**폴더 비교**는 "왼쪽만 / 오른쪽만 / 내용 다름 / 같음"을 재귀로 나열하고, 행을 클릭하면 그 파일의 텍스트 비교로 들어갑니다.
**3방향 병합**은 "기준 + A + B"를 자동 병합하고 충돌을 나열합니다. 결과는 새 탭으로만 열리고 원본 파일은 덮어쓰지 않습니다.

## 파일과 검색

사이드바는 두 페이지: **개요**(스크롤에 따라 현재 절을 강조)와 **파일**.

- 디렉터리 트리는 필요할 때 펼칩니다. 우클릭으로 만들기·이름 바꾸기·삭제 — 삭제는 **휴지통**으로, 폴더는 비어 있을 때만 삭제됩니다
- 검색은 Rust에서 실행하고 바이너리와 4 MB 초과 파일을 건너뛰며, 최대 200건을 파일별·줄 번호와 함께 돌려줍니다
- `.*`로 정규식, `Aa`로 대소문자 구분
- **모두 바꾸기**는 파일을 넘나들며 실행합니다. 먼저 한 번 확인하고, 각 파일을 고치기 전에 스냅숏을 남깁니다
- 열린 문서는 실시간 감시(`ReadDirectoryChangesW`): 현재 탭은 조용히 다시 읽고, 배경 탭은 노란 점이 붙고 전환할 때 묻습니다

|---|---|
| **한 번에 정리** | `Ctrl+Shift+F` — JSON은 검증 후 다시 정렬(오류 시 파일을 건드리지 않고 줄·열만 알림), Markdown은 빈 줄 보완과 목록 기호 통일, 나머지는 줄 끝 공백 제거. `Ctrl+Z` 한 번이면 전부 되돌아갑니다 |

| **집중 모드** | `F9`로 탭·사이드바·상태 표시줄·메뉴를 접습니다. 제목 표시줄은 사라지지 않고 28%로 옅어집니다 (사라지면 창을 끌 수도 닫을 수도 없음) |

| **인코딩** | 상태 표시줄의 `UTF-8`이나 `LF`를 눌러 인코딩(GBK / UTF-16 / BOM)과 줄바꿈을 바꿉니다 |

## 성능

로컬 측정(Windows 11, x64, release 빌드):

| 상황 | 지표 |
|---|---|
| 600문단 문서에서 입력 | 키 입력당 **9.1 ms** |
| 10.8 MB / 77,866 블록 열기 | **1.14 s**, DOM에는 약 48블록만, 멈춤 없음 |
| 같은 문서에서 입력 / 스크롤 / 실행 취소 | p50 **0.3 ms** / 프레임당 약 **17 ms** / 단계당 **37 ms** |
| CodeMirror 6 일반 텍스트 | 5만 줄 **49 ms**, 10만 줄 **20 ms** |
| 메모리 / 설치 파일 | 갓 실행 시 약 **170 MB** / **2.63 MB** |

거대한 Markdown은 뷰포트 렌더링을 씁니다: 보이는 블록만 DOM에 있고 나머지는 레코드로 남습니다.
실행 취소 스냅숏이 레코드 배열이라, 한 글자를 쳐도 문서 전체를 복사하지 않습니다.

## 데이터

파일 읽기와 쓰기는 전부 이 컴퓨터 안에서만 일어납니다 — **네트워크 없음, 업로드 없음, 수집 없음**.
저장하지 않은 탭의 초안은 로컬 앱 데이터 폴더에 있고 다음 실행 때 복원할지 묻습니다. 기록 스냅숏은 같은 위치의
`history/`에 있어 문서 폴더와 완전히 분리됩니다.

## 알려진 제한

- PDF는 시스템 인쇄 대화상자를 거치므로 레이아웃이 인쇄 출력을 따릅니다
- 3방향 병합은 자동 병합 + 충돌 목록이며 4분할 시각 병합기는 없습니다 (복잡한 충돌은 텍스트 비교로 블록 단위로)
- 수식은 미리보기에서만 렌더링되고 WYSIWYG에서는 소스로 보입니다. Mermaid는 지원하지 않습니다
- 파일 간 바꾸기는 UTF-8만 처리합니다. GBK 등은 조용히 다시 인코딩하지 않고 건너뜁니다
- 파일 트리 자체는 감시하지 않습니다. 외부에서 바뀌면 우클릭 메뉴의 **새로 고침**
- 플랫폼별 설치 파일은 해당 OS에서 빌드해야 합니다 (`docs/构建说明.md` 참고). 설계와 포팅 문서는 `docs/` 에 있습니다
