## 给「要开发 mac / Linux 版」的读者的最短路径

1. 读《跨平台移植》§0～§1 的总览表，先知道**只有 4 项是阻断级**，不必整体重写。
2. 读《架构设计》§3（运行时结构）和 §4（前端分层）——业务逻辑不用改，但要知道边界在哪。
3. 按《跨平台移植》§9 的 M1～M6 里程碑推进，每步都有验收标准。
4. 遇到「改了没反应」先看《构建说明》§二的三条铁律（前端是编译期内嵌的）。
