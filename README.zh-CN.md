# EZNotepad

> 一个 **5 MB** 的桌面小工具：Markdown 写作 + 文本编辑 + 文件对比。
> 免安装、不联网、双击即用。
> 界面支持 9 种语言，默认跟随系统，可在 **设置 → 语言** 里手动切换。

## 下载

| 产物 | 适合谁 |
|---|---|
| `EZNotepad_<版本>_x64-setup.exe` | **安装版** —— 安装向导 + 文件关联，双击 `.md` / `.txt` 直接在这里打开 |

## 替换掉什么

| 以前用 | 为什么 | 现在 |
|---|---|---|
| 记事本 | 开任意文本、换编码、看日志 | 一样能开，外加行号、高亮和大纲 |
| Typora | Markdown 边写边看 | 三种模式，体积只有二十分之一 |
| BeyondCompare | 对比两个文件 | 并排、字符级标记，`F7` / `F8` 逐处跳转 |

## 三种模式

| 模式 | 做什么 | 快捷键 |
|---|---|---|
| **所见即所得** | 行首敲 `# ` 出标题，`**加粗**` 边打边变 | `Ctrl+1` |
| **编辑** | 原始 Markdown / 源码，CodeMirror 6，行号与折叠 | `Ctrl+2` |
| **预览** | 只读渲染，为阅读而生 | `Ctrl+3` |

`.md` 三种模式全支持；`.json` 有校验和错误定位；`.txt` `.log` `.csv` 与代码文件
（`.js .ts .py .rs .go .html .css .sql .yml` …）只有编辑 / 预览，当纯文本编辑器用。
新建文件先选类型（Markdown / 纯文本 / JSON / CSV / 代码）。

## 编辑

| | |
|---|---|
| **块级** | 行首 `# ` 标题、`- ` / `1. ` / `- [ ] ` 列表（6 级）、`> ` 引用、` ``` ` 代码、`---` 分割线 —— 标记只要求落在行首 |
| **行内** | `**粗**`、`*斜*`、`~~删~~`、`` `码` ``、`[文字](链接)` 边打边渲染 |
| **撤销 / 重做** | 工具行最左两个箭头（退到头变灰），`Ctrl+Z` / `Ctrl+Y`，`Ctrl+Shift+Z` 同重做 —— 所见即所得与纯文本各走自己的历史栈，互不干扰 |
| **表格** | `Ctrl+Shift+T` 插入；`Tab` 走格子，`Enter` 跳到下一行同列，右键增删行列与对齐 |
| **图片** | 粘贴截图、拖入文件或 **插入 → 图片**：文件会复制到文档旁的 `assets/`。拖右下角改宽度，或手写 `![说明\|300](a.png)` |
| **公式** | `$a^2+b^2=c^2$` 行内、`$$ … $$` 整块，预览里由 KaTeX 排版（有公式才加载） |
| **提示块** | `> [!info]` / `warning` / `danger` / `success`，GitHub 的别名也认 |
| **块手柄** | 行首浮出 `+` 与 `⋮⋮`：插入新块，或把当前块换成别的类型 |
| **粘贴** | 多行文本按 Markdown 解析成真正的标题、列表、表格，而不是糊成一段 |

换块类型（`Ctrl+Shift+Q` 引用、`Ctrl+Shift+K` 代码…）、**格式**菜单、右键菜单和
`Ctrl+Shift+P` 命令面板走的是同一套命令，不适用的项自动变灰。

### 查找替换

一个浮层两种状态：`Ctrl+F` 只聚焦，`Ctrl+H` 直接展开替换行。**所见即所得里也能直接搜**，
高亮画在渲染层上，不往正文里塞标签。

`Aa` 区分大小写 · `.*` 正则 · 全词匹配（只有两端都是英文字符时才加词边界，中文没有词边界）·
选区中查找 · `↵` 在查询里换行。同一段文字内的匹配就地替换，只有跨粗体、链接这类格式边界时才提示切到编辑模式。

## 速记

`Ctrl+Shift+M`（或点菜单栏的 **速记**）打开一份固定的临时笔记：

- **不用保存** —— 停下约 0.35 秒自动写盘，关标签、关窗口前先补写完；没有「未保存」提示，也不会问你要不要保存
- **位置固定** —— `<应用数据目录>/quicknote.md`，「文件 → 速记」里能看到它在哪，也能一键在资源管理器里定位
- **接着上次写** —— 打开时光标就在末尾；**插入当前时间** 补一句 `2026-11-03 09:20`
- **清空有后路** —— **清空速记** 先存一份到「历史版本」，需要时能找回

它仍是普通 Markdown 标签（能切模式、导出、搜索），只是不进「最近打开」，也不随上次的标签一起恢复。

## 对比

`Ctrl+D`（或 `Ctrl+Shift+N`）打开对比窗口，默认是空的 —— 怎么进由你决定：

- **两个文件** —— 侧栏「文件」页里用 `Ctrl` / `Shift` 多选，右键 → **比较这两个文件**（右键的那个在左边）
- **两段文本** —— 点 **粘贴两段文本**，两边直接粘，不落盘也能比
- **直接改** —— 点 **编辑** 两侧都变可写；**保存** 只写回真有磁盘文件的那一边

行级标记指出哪行变了，字符级标记指出变了哪几个字。`F7` / `F8` 逐处跳，**导出报告** 生成独立的 HTML 对比页。
改完左边不必手抄：工具栏的 **复制到右侧** / **复制到左侧** 把**当前这一处差异整段**推到另一边，方向跟着光标在哪一栏变；`Alt+←` / `Alt+→` 是同一件事，加 `Ctrl` 就是「推完接着看下一处」，一路按下去能把整篇合完。
右侧刻度尺对应整篇的位置——悬停看行号，点击或拖动定位；**差异清单** 把每处改动列成可排序、可筛选的列表（位置 / 类型 / 行数）。
**排序** 把两侧的行按字典序重排（空行留末尾），顺序噪音不再淹没真正的增删。
编辑态下打字、回车换行、缩进、删选区、排序都能 `Ctrl+Z` 撤销 / `Ctrl+Y` 重做（焦点在工具栏上也管用）。
工具栏上也有这两个按钮，退到头时自动变灰；窗口拉窄时这一行先收成图标，不会把右边的按钮裁掉。
单侧上限 8MB / 5 万行，超出会说明原因，不静默失败。

**文件夹对比** 递归列出「左边独有 / 右边独有 / 内容不同 / 相同」，点一行就进文本对比。
**三向合并** 选「基准 + A + B」，自动合并并列冲突 —— 结果只开新标签，绝不覆盖原文件。

## 文件与搜索

侧栏两页：**大纲**（滚动时高亮当前章节）和 **文件**。

- 目录树按需展开；右键新建、重命名、删除 —— 删除进**回收站**，文件夹只允许删空目录
- 搜索在 Rust 里跑，跳过二进制与 4 MB 以上的文件，最多 200 条，按文件分组带行号
- `.*` 切正则，`Aa` 切大小写
- **全部替换**跨文件，先问一次，每个文件改前都留快照
- 打开的文档实时监听（`ReadDirectoryChangesW`）：当前标签静默重载，后台标签亮个黄点，切过去时再问

## 其它

| | |
|---|---|
| **一键格式化** | `Ctrl+Shift+F` —— JSON 校验 + 重排（出错时不动文件，只报行列），Markdown 补空行、统一列表符号，其余去行尾空白。一次 `Ctrl+Z` 全还原 |
| **历史版本** | 每次保存前留一份（每文件 60 份、共 20 MB）。**查看** 只读打开，**恢复** 写回编辑器 —— 不按 `Ctrl+S` 就不落盘 |
| **导出** | 单文件 HTML（样式内联、图片转 data URI）；PDF 走系统打印对话框 |
| **快捷键** | 设置 → 快捷键 可改任意一条；自定义优先，**重置**恢复单条，**恢复默认**清空全部 |
| **专注模式** | `F9` 收起标签、侧栏、状态栏和菜单；标题栏只降到 28% 不消失，否则窗口没法拖、没法关 |
| **单实例** | 再双击一个文件不会开第二个进程，路径交给已在运行的窗口 |
| **编码** | 点状态栏的 `UTF-8` 或 `LF` 换编码（GBK / UTF-16 / BOM）与行尾 |

## 性能

本机实测（Windows 11，x64，release 构建）：

| 场景 | 指标 |
|---|---|
| 600 段文档里打字 | 每键 **9.1 ms** |
| 打开 10.8 MB / 77,866 块 | **1.14 s**，DOM 里只留约 48 块，不卡 |
| 同一文档打字 / 滚动 / 撤销 | p50 **0.3 ms** / 每帧约 **17 ms** / 每步 **37 ms** |
| CodeMirror 6 纯文本 | 5 万行 **49 ms**，10 万行 **20 ms** |
| 内存 / 安装包 | 干净启动约 **170 MB** / **2.63 MB** |

超大 Markdown 走视口渲染：只有看得见的块进 DOM，其余全是记录；撤销快照就是记录数组，
敲一个字不会复制整篇文档。

## 数据

所有文件只在本机读写 —— **不联网、不上传、不埋点**。未保存标签的草稿放在本地应用数据目录，
下次启动时问你要不要恢复；历史快照在同目录的 `history/` 下，跟你的文档目录完全分开。

## 已知限制

- PDF 走系统打印对话框，排版跟打印输出一致
- 三向合并是「自动合并 + 冲突列表」，没有四栏可视化合并器（复杂冲突用文本对比逐块过）
- 公式只在预览渲染，所见即所得里显示源码；暂不支持 Mermaid
- 跨文件替换只处理 UTF-8，GBK 等编码直接跳过，不会悄悄整篇重编码
- 文件树本身不监听，外部增删后在右键菜单里 **刷新**
- 各平台安装包必须在对应系统上构建（见 `docs/构建说明.md`）；架构设计与跨平台移植说明在 `docs/` 目录
